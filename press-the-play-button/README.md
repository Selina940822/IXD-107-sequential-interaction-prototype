# Press the Play Button

An old television with a slow, resistant play button. Press and hold until it clicks, then release and the curtains on the screen open. The reset button in the corner starts it over.

Source: https://claude.ai/artifact/BKCXwUYVbn13MCY6kguANX

## Files
- `index.html` contains the whole artifact: inline SVG, CSS and JavaScript. Sound is made with the Web Audio API.

## Running
There are no dependencies or build step. Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server
```
